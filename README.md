# switch-opensteamtool
主要用于切换open steam tool的启用状态，另外可绑定大小号选择启用并启动小号，禁用并启动大号。**代码完全由AI编写**

>[!NOTE]         
>OpenSteamTool项目连接https://github.com/OpenSteam001/OpenSteamTool

>目前功能

   显示opensteamtool状态：未启用
1. 禁用steamtool并启动 （个人资料名称）
2. 启用steamtool并启动 （个人资料名称）
3. 切换steamtool状态
4. 打开3A社区
5. 校对游戏版本
    1. 核对本地文件
    2. 从github仓库下载导入文件
6. 打开游戏清单lua文件夹
7. 打开OpenSteamTool
8. 强制结束 Steam 进程
9. 设置
    1. 更换1、2的启动账号绑定
    2. 更换仓库
